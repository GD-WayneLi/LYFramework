# Event 模块规范

本文件继承 `Assets/Scripts/LYFramework/AGENTS.md`，适用于事件注册、同步派发和延迟派发代码。

## 事件契约

- 事件类型本身是路由键；同步和延迟派发必须使用同一个实际事件类型。
- 明确是否支持基类/接口多态派发。未显式设计前，只按具体注册类型精确匹配。
- 保持监听器调用顺序可预测，并定义重复添加同一委托的行为。
- 事件对象若来自 ReferencePool，必须明确由发送方还是 EventManager 释放。

## 线程与重入

- 默认监听器在 Unity 主线程执行。
- 若允许后台线程 `Post`，入队、Dispose 和状态检查必须线程安全；后台线程不得直接调用监听器。
- 必须支持或明确禁止派发期间 Add/Remove/Send/Post。实现不能因集合被回调修改而失效。
- 一个监听器抛异常时，是否继续调用其他监听器必须有统一策略并记录上下文。

## 生命周期

- Dispose 后不再接受事件，且要释放监听器、待派发事件及 sender 引用。
- Update 每帧处理的事件边界必须明确：派发过程中新增的 Post 默认留到下一轮，避免单帧无限循环。

## 已知状态

- 当前延迟队列保存的是 `IEvent`，Update 再次调用泛型 Send 时会按 `IEvent` 路由，无法命中具体事件监听器。
- 当前 Queue 不是线程安全队列，Dispose 也没有清理待派发事件。

## 最低验证

- 每种事件同时覆盖 Send 与 Post，并断言类型、sender、顺序和调用次数一致。
- 派发中增删监听、监听器抛异常、递归发送、Dispose 后调用。
- 若支持后台 Post，增加并发入队和主线程消费测试。
